3Inbound call lifecycle

The core flow: a caller dials in, Vapi's AI answers, and the end-of-call report drives the call log, CRM delivery and owner notifications.

sequenceDiagram
  participant Caller
  participant Vapi
  participant WH as POST /api/calls/webhook/vapi
  participant DB as Prisma/Neon
  participant CRM as Nexleon/Custom
  participant Notify as Email/SMS/WhatsApp
  Caller->>Vapi: Calls the assigned number
  Vapi->>Vapi: AI (Haiku) answers, captures name/phone/intent
  Vapi->>WH: end-of-call-report (customer, analysis.structuredData, transcript)
  WH->>WH: eventType == "end-of-call-report"? else ack and stop
  WH->>DB: find Conversion by vapiAssistantId
  WH->>WH: callerName = structuredData.name ?? customer.name ?? "Unknown"
  WH->>DB: create CallLog (outcome, name, number, summary, analysis)
  WH->>CRM: deliverCallToCrm() (see flow 4)
  WH->>Notify: callSummaryEmail + owner SMS/WhatsApp (best-effort, plan-gated)
  WH->>DB: recordUsage() then settleAfterCall() (trial/billing reconcile)

5Trial / billing lifecycle

Trial converts or lapses into a grace window; active plans renew and emit usage alerts; failed charges suspend and freeze calls.

stateDiagram-v2
  [*] --> Trialing: subscribe (card saved)
  Trialing --> Active: minutes/days exhausted then auto-charge (planActivatedEmail)
  Trialing --> Grace: trial lapses, no conversion (graceStartedEmail)
  Grace --> Active: picks a plan (number kept)
  Grace --> Released: grace ends then number released (graceEndedEmail)
  Active --> Active: renewal; usageThresholdEmail at 50/80/90%
  Active --> PastDue: charge fails
  PastDue --> Suspended: unresolved (assistant detached, calls frozen)
  Suspended --> Active: admin reactivates (accountReactivatedEmail)

6System emails pipeline

Every lifecycle email renders from an editable template (DB row with code-default fallback), with variable substitution and an editable header/footer.

flowchart LR
  T["Trigger (signup, call, billing, staff)"] --> S["sendTemplate(key, to, vars)"]
  S --> R["renderEmail(): DB EmailTemplate row then code default fallback"]
  R --> V["substitute {{vars}} + escape values"]
  V --> W["wrap in editable header/footer + from-name"]
  W --> EN{"enabled? (alwaysOn always sends)"}
  EN -->|Yes| SM["sendEmail() then Nodemailer SMTP"]
  EN -->|No| X["skip"]
  Admin["Admin → System Emails page"] -->|edit subject/body/toggle| DB[("email_templates")]
  DB --> R
